# Number Guessing Game & Word Counter

## Project Overview
This project is a beginner-friendly Python application that combines a Number Guessing Game and a Word Counter tool.

## Features
- Generates random numbers between 1 and 100.
- Allows users to guess the secret number.
- Counts the number of attempts.
- Provides a scoring system.
- Reads text files.
- Counts total words.
- Displays word frequency.
- Handles invalid inputs and missing files.

## Technologies Used
- Python
- Random Module
- Collections Module
- File Handling
- While Loops
- Functions
- Conditional Statements

## How to Run
1. Install Python on your computer.
2. Download the project file.
3. Open the terminal.
4. Run the following command:

```bash
python number_guessing_word_counter.py
```

## Sample Input
```text
python is easy
python is powerful
```

## Sample Output
```text
Total words: 6

Word Frequency:
python : 2
is : 2
easy : 1
powerful : 1
```

- Using loops and conditional statements.
- Working with text files.
- Counting words and frequency.
